# Ferrio Bot

Discord bot showing a random unusual holiday of the day from [Ferrio](https://ferrio.app) via the `/ferrio` slash command.

## Developing

1. Check out the repo.
2. Build it with the `./gradlew build` command.
3. Ask the author about the bot token.
4. Start the app with the token in the `FERRIO_TOKEN` environment variable.
   Optionally set `FERRIO_LOG_LEVEL` (`TRACE`, `DEBUG`, `INFO`, `WARN`, `ERROR`, `FATAL`, `OFF`; `INFO` by default).

The token is read only at runtime and never ends up in the JAR or the Docker image.
